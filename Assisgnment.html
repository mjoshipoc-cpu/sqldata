Environment: ASP.NET MVC 4.0, C#, jQuery, SQL Server 2014 Project overview: Insight is a solution built for BPO operations providing integrated services including reporting, LMS (Learning Management System), QMS (Quality Management System), and WAT (Work Activity Tracker). The LMS module manages learning modules and training assessments for agents. The QMS module enables quality checks of agent work as monitored by QA/TL based on management-defined parameters. The solution also includes performance dashboards for Agents and Team Leaders tailored per client requirements. Roles & Responsibilities: Involved in coding, designing, and maintenance of the application across modules (LMS, QMS, WAT, Reporting). Collaborated within a team of 8 members to deliver features across the solution. Developed front-end functionality using jQuery and backend logic in C#/ASP.NET MVC 4.0. Worked on SQL Server 2014 for data storage and retrieval supporting reporting and dashboard modules.
