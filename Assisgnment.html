Project: HEDIS Abstractor.ai- Automated HEDIS Clinical Data Extraction Pipeline Environment: Snowflake Cortex AI, Claude Sonnet 4.5, Snowflake AI_PARSE_DOCUMENT, SQL, YAML Project overview: HEDISAbstractor.ai is an automated healthcare data processing pipeline built on Snowflake Cortex AI that analyzes Electronic Medical Records (EMRs) to evaluate patient compliance with various HEDIS quality measures. It transforms unstructured EMR PDF documents into validated, structured HEDIS measure outcomes, enabling automated quality reporting, compliance tracking, and clinical data extraction at scale. Roles & Responsibilities: + Built automated PDF ingestion pipeline to detect new EMR files from a Snowflake stage and extract text using Snowflake's AI_PARSE_DOCUMENT. + Designed measure-specific LLM prompts to extract structured clinical information from unstructured EMR. + Implemented ICD code extraction to identify diagnosed conditions and map relevant codes from clinical documentation. + Generated structured JSON summaries of patient demographics, diagnoses, medications, and other clinical details. + Built secondary LLM-based validation layer producing confidence scores and an evidence matrix linking extracted data back to source text for auditability. + Designed idempotent upsert logic in Snowflake tables to prevent duplicate records during reprocessing.
