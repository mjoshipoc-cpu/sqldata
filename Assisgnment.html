Project overview: A GenAI-powered assistant that allows business users to query HEDIS/healthcare reporting databases using plain English instead of SQL. The tool converts natural language questions into optimized SQL queries using schema-aware prompting and returns results in a conversational format, reducing dependency on technical teams for ad hoc data requests. Roles & Responsibilities: Designed prompt templates with schema grounding and few-shot examples to improve SQL generation accuracy. Integrated LLM API (OpenAI/Azure OpenAI) with existing SQL Server reporting database. Built a lightweight front-end using Streamlit for business users to interact with the assistant. Implemented guardrails to validate and sanitize LLM-generated SQL before execution. Benchmarked query accuracy against manually written SQL for common report requests.
